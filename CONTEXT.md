# Client Web Business & Vibe Coding Studio: Context

## Project Mission
To build, customize, legally protect, and sell high-converting, mobile-responsive local business websites and micro-SaaS assets using rapid AI-assisted declarative synthesis (vibe coding) with zero ongoing server maintenance liability.

## Baseline Inventory & Assets

### 1. Core Agency Platform
- `index.html`: Vanguard Web Studio high-converting agency portfolio with service packages, pricing ($799 / $1,499 / $2,499), showcase cards, and client intake form.
- `DESIGN.md`: Machine-readable design token specification (colors, typography scales, glassmorphism card elevation, mobile breakpoints) to eliminate "AI beige."

### 2. Live Niche Demos
- `demos/local-business/index.html`: **Apex Roofing & Remodeling** (Amber Gold & Navy Blue theme, instant quote calculator, 5 core sections).
- `demos/plumbing/index.html`: **BlueFlow Plumbing & Drains** (Cyan & Slate theme, emergency dispatch booking, 45-min arrival guarantee).
- `demos/dental/index.html`: **Willow Dental Care** (Teal & White clinical theme, $99 new patient exam card, anxiety-free comfort amenities).

### 3. Legal & Commercial Safeguards
- `contracts/web_design_agreement.md`: Master freelance agreement featuring limitation of liability, 50% upfront deposit terms, 2-round revision caps, and IP assignment conditioned upon 100% final payment.
- `contracts/client_proposal_and_scope_template.md`: 1-page proposal sheet to quote clients.

### 4. Playbooks & Guides
- `COMPLETE_ROADMAP_GUIDE.md`: 7-Phase end-to-end sales and delivery roadmap (from Google Maps prospecting to $149/mo retainers).
- `LEARNING_ROADMAP_BUILDING_GREAT_WEBSITES.md`: 4-level progressive curriculum for mastering web creation.
- `VIBECODED_SAAS_EXIT_PLAYBOOK.md`: Valuation benchmarks, due diligence checklists, and escrow mechanics for exiting web assets.

## Tech Stack & Architecture
- **Frontend**: HTML5, Tailwind CSS (via CDN), Google Fonts (*Plus Jakarta Sans*).
- **Interactivity**: Vanilla JavaScript event handling.
- **Form Delivery**: Web3Forms / Formspree (zero-backend email routing).
- **Deployment**: Vercel / Netlify / GitHub Pages (1-click static deployment).
